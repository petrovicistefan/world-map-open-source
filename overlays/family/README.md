# Category: `family` (children)

Spaces for **children**: playgrounds, indoor play, crèche / Kita / after-school.  
Also practical facilities when out with kids (changing table, nursing room, stroller-friendly).

| Kind | Use for |
|------|---------|
| `playground` | Outdoor playgrounds |
| `indoor_play` | Indoor play / soft play |
| `creche` | Crèche / Kinderkrippe (public listings) |
| `kita` | Kita / daycare (public listings) |
| `after_school` | After-school / Hort |
| `changing_table` | Public changing tables |
| `nursing_room` | Nursing rooms |
| `family_restroom` | Family toilets |
| `stroller_friendly` | Stroller-friendly access |
| `pediatric_clinic` | Pediatric practices (public) |

**Not this layer:** charity banks, toy libraries, mutual-aid — those belong elsewhere or not at all.

## Safety

- Creche/Kita: **public listings only** — no private home daycare addresses.
- No PII of minors.
