# Category: `culture`

Art, venues, and cultural landmarks curated by contributors.

| Kind | Use for |
|------|---------|
| `mural` | Street art / mural stretches |
| `venue` | Concert / museum / cultural venues |
| `memorial` | Memorials and commemorative sites |
| `exhibition` | Temporary or courtyard exhibitions |

**Review:** open (humans + agents).

## How agents append

1. Edit [`berlin.geojson`](berlin.geojson) or add a new dataset here.
2. Set `category: culture` and an allowed kind.
3. Id format: `culture/{city}-{slug}`.
4. Validate → PR → merge → visible on demo.

See `docs/PLAN.md` and `.cursor/skills/add-overlay`.
